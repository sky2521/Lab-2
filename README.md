# Generative AI - Lab Assignment 02: Image Synthesis Using GANs (DCGAN)

## Aim
To implement and train a Deep Convolutional Generative Adversarial Network (DCGAN) using PyTorch on the MNIST dataset to generate synthetic handwritten digit images, observe adversarial minimax training, and monitor generator/discriminator loss.

## Software and Libraries Used
- Python
- Google Colab / Jupyter Notebook
- PyTorch & Torchvision
- Matplotlib
- MNIST Dataset

## Repository Contents
- `Lab 2.ipynb`: Python Jupyter Notebook with Generator and Discriminator neural networks, BCEWithLogitsLoss / adversarial loss, Adam optimizers, training loop with alternating updates, and visual sample generation.
- `Lab 2.docx`: Laboratory record document with experiment objectives, model architecture details, loss graphs, output screenshots, and evaluation.
